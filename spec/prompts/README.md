# Design conversation transcript

ETHGlobal's spec-driven rule: *"you must include all spec files, prompts, and planning artifacts in your submission repository. Judges need to see the full picture of how you directed the AI, not just the generated output."*

## What belongs here

- The full transcript of the design conversation that produced `spec/WHETSTONE.md`, `spec/RUNBOOK.md` and `spec/DESIGN-NOTES.md`
- Any adversarial review passes over the specification, with their source named
- Prompts used to generate implementation code, as it lands

## ⚠️ Before committing the transcript

**Strip secrets.** No API keys, private keys, account credentials, or `.env` contents.

**Name the sources.** If any review or critique came from a different AI model, say which — the attribution rule covers all AI involvement, not just the tool that wrote the code.

**Keep the substance, trim the tone.** Strategic reasoning about which sponsor prizes were worth pursuing is honest and can stay, but it does not need to be reproduced line by line: sponsors are also the judges. Summarize the prize-selection reasoning; keep the design reasoning intact.
